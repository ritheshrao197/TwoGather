# **App Name**: Shared Spaces

## Core Features:

- Split Access Entry: Secure entry point with individual access keys for Person A and Person B.
- Personal Page Curation: Each person has a private page curated by their partner, including wishes/messages, a memory wall, notes, and a personal collection. A generative AI tool will find memories or suggest captions when adding new entries to the Memory Wall.
- Secure Partner Password Flow: Allows one partner to securely set a password for the other, with verification and recovery options.
- Shared Archive: Unlocks a shared space with a timeline, idea board, and shared presence detection when both users are active.
- Media Upload Flow: Secure upload flow with signed URLs and thumbnails for images, videos, and audio clips.
- Presence Detection: Real-time presence detection to unlock shared content when both users are online.
- Settings Management: Comprehensive settings panel for profile, security, privacy, and theme customization.

## Style Guidelines:

- Primary color: Muted lavender (#C7C4E2) for a calm, harmonious feel.
- Background color: Soft Midnight Blue (#1F2A44) to create a dark, intimate setting.
- Accent color: Mint Green (#A7E3C3) to highlight interactive elements and create visual contrast.
- Headings font: 'Poppins' (sans-serif) for clear, contemporary titles.
- Body font: 'Inter' (sans-serif) for a readable and accessible user interface.
- Use simple line icons for a clean, modern aesthetic.
- Subtle transitions and micro-interactions to enhance user engagement without being distracting.
